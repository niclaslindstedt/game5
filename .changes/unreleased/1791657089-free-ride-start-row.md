---
type: Changed
title: Pick any slope, and how the ride begins, on its own row
---

The free ride's start card drops its GRADE row: the RUN row now lists every slope on the mountain, of any colour, and nothing else. How the ride begins is a new START row of its own — on skis, the paramotor, the balloon, the snowmobile, the helicopter or the afterski — and the pause card's PISTE MAP carries the same two rows, so any run or any ride can be picked mid-ride. On a free ride's pause card the PISTE MAP is now a lit row of its own under RESUME.
