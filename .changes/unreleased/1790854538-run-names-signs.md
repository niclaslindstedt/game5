type: Added
title: Every run has a name and a sign at its head
---

Every run of a ski area is now named in the voice of its country — gentle names for the greens, bolder ones for the reds, fearsome ones for the blacks, and the cat tracks named as ways, roads, tracks and traverses — and a sign stands at the head of each one and where a lane turns off: a board on a post with the run's colour mark, its number, its name and an arrow the way it goes. The news column names each run as you ski onto it.
