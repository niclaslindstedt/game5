The free ride's real mountainsides are filed by country: the start card's SHAPE row lists the countries (the Nordic ones first) and a new PEAK row picks one of that country's mountainsides, and the GRADE row hides the mountainsides whose real ski area has no run of that colour. The kind-of-country row is now called CLIMATE. Each mountainside is downloaded only when you pick it, so the game itself loads faster.
