Whether something reads as MOVING (flakes streaming past, a gap between one frame's
draw and the next) is invisible in one frame. The snowfall lab draws it: every other
slice hidden through `renderer.setHidden(HIDEABLE.filter(…))`, then N frames at
1/60 s each drawn onto one black cell with `globalCompositeOperation = "lighten"`, so
each particle's way across the picture is a track — dotted where it strobes, unbroken
where it is smeared. A number about what the LENS does (its velocity) is read off
`renderer.lensPose()` every frame through the same tracker the shader's uniforms come
from, never off the skier.
