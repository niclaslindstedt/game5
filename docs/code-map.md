# Where new code goes: the code map

The file-by-file map of the repository: every subject, the modules it lives in (engine, app, labs, tests) and the skill that owns it. [`AGENTS.md`](../AGENTS.md)'s "Where new code goes" is the index of these rows by area, with the pieces that belong to no skill; this page is the full table. Look a subject up here before adding a file, and add its row here when a new subject lands. The architecture behind it — the three layers and the one direction of dependency — is [`architecture.md`](architecture.md).
