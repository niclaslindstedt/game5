Privacy Policy

Fall Line collects nothing. There is no account, no sign-in, no analytics, no advertising, and no server of ours anywhere that knows you played.

Applies to the web game and to any app built from it. Last updated 2026-09-23.

What the game stores

The game remembers a few things so that it is still the game you left. All of it is held by your own browser or app, on your own device, in ordinary local storage:

  • Your settings.
  • Your best times down each piste, the ghost runs that set them, and your campaign's results.

In the web game none of it is transmitted: clearing the site data in your browser deletes all of it, and there is no copy elsewhere to restore it from.

In the iOS app, the same things — except the picture settings and the touch controls, which belong to that device — are also kept in your own iCloud (Apple's key-value storage, under the Apple ID the device is signed into), so your other devices can pick up where this one left off. That copy is yours and Apple's; we have no access to it and no server that receives it. Signing out of iCloud, or turning iCloud off for the app, keeps everything on the device alone.

What the game sends

Nothing of ours, and nothing to us. The web version loads the game's own files from its own address once, then runs offline. The only connection you can cause is a link you press yourself — the source repository, or a credit — which opens in your own browser and is then between you and that site.

Children

The game is suitable for a general audience and collects no personal information from anybody, of any age. There is nothing to buy inside it and no way to communicate with another player through it.

Hosting

The web version is served by GitHub Pages. Like any web server, it sees the requests that fetch the page. We neither receive nor keep those logs, and we run no other service that the game talks to.

Changes

If a future version of the game ever gains something that does leave your device, this page changes in the same release that adds it.
