**Cards stay still while you step a row.** Stepping a run on the piste map or the start card no longer nudges the whole card a few pixels: the line of figures under the chart (the grade, the length, the vertical, the kickers) is held to the chart's own width instead of widening its panel, a row's arrows no longer shift with the length of the word between them, and a row whose value can run to two lines (EARLY WINTER, HIGH CLOUD) keeps that room on every value so the rows under it stay put. The skis card no longer jumps when POLES is stepped to NONE and back, and the start card's rows on a phone held sideways keep their arrows in one place.
