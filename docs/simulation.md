# Simulation

The headless harness (`engine/sim/simulate.ts`) runs the REAL engine — `createGame`, `step`, the bot skier (`engine/sim/bot.ts`) — with no renderer attached and reports what happened. It is how a ski, snow, bot or generator change is MEASURED rather than argued: run it before and after, read the diff, paste both tables in the PR. `tests/simulation_test.ts` holds the bot to finishing what the generator builds, and `tests/determinism_test.ts` holds the digest.

## The harness

`simulateRun(seed, options?)` builds the seed's map (or skis `options.level`, a synthetic one in the tests), stands the bot on the start line's first slot with **no lights** (`countdown: 0`) and, by default, **nobody else on the line** (`rivals: 0` — a solo run is the measurement; `--rivals 3` is the race), and steps it at the engine's own 120 Hz until the finish line or `maxSeconds`. It returns a `RunReport`:

| Field                            | Meaning                                                                                                            |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `finished`, `time`               | The finish line, and the run clock at it (or at the timeout), s                                                    |
| `laps`, `lapTimes`               | Always one run on a generated map (R16); the table's `splits` column is the run's own time                         |
| `checkpoints`, `crossings`       | Gates credited, of the run's total — the start gate, every gate down the piste, the finish line                    |
| `trackLength`                    | The piste, m — on a resort (R25) the course raced down it (R28)                                                    |
| `powder`                         | How much of the piste's centreline lies under a drift (R17), 0..1 — what the catalog's rows are read against       |
| `topSpeed`, `meanSpeed`          | m/s; the mean is plan distance over the run clock                                                                  |
| `airTime`, `bestAir`, `jumps`    | Seconds of air summed over flights longer than 0.3 s, the longest flight, how many                                 |
| `harshLandings`                  | Landings the legs could not take whole (`land.harsh`)                                                              |
| `treeHits`, `bumps`              | Trunks met and (in a race) rivals shouldered                                                                       |
| `wipeouts`                       | Times the skier was thrown (`crash.ts`) — the table's `wipe`                                                       |
| `resets`, `autoResets`, `missed` | Resets, the engine's own among them, and gates skied past (a slalom gate's at three seconds on `time`, R28)        |
| `out`, `trap`                    | A discipline's run (`--mode`): how it went out of the race under the strict gates (`dsq`/`dnf`, why, at which gate — then not `finished`), and the speed through a speed course's trap (a downhill's, a super-G's — on a speed track, its timing zone, whose time is then the run's `time` and whose speed its `mean`), m/s |
| `place`                          | Where the bot finished against the field (1 solo)                                                                  |
| `score`                          | The score the run banked (`tricks.ts`): the bot turns nothing, so it is its air and the ground its flights covered |
| `digest`                         | FNV-1a over the skier's position and speed every quarter second — the determinism fingerprint                      |

## The CLI

```sh
npm run sim                        # seeds 1..8, solo, top to bottom
npm run sim -- --count 20          # seeds 1..20
npm run sim -- --seeds 3,7,38      # these seeds
npm run sim -- --rivals 3          # a whole race
npm run sim -- --skis eagle        # one pair of the catalog (the all-mountain pair when left out)
npm run sim -- --skis all          # the catalog: every pair's table, then who was quickest on each seed
npm run sim -- --tricks            # each seed's map of one piste with its terrain park laid (R20)
npm run sim -- --no-poles          # the bot skis without poles (the player's hard mode)
npm run sim -- --region fell       # each seed's map built in another kind of snow country (R21)
npm run sim -- --weather storm     # every map under one sky (R19) — the bot in a storm's wind
npm run sim -- --mode downhill --skis eagle   # a discipline's race: the course set over each seed's map (slalom R31, downhill R32, superG R33, giantSlalom R36 — its first run, speedSki R34 — its qualifying run, skiCross R35 — its qualification)
npm run sim -- --mode skiCross --skis wolverine --heat   # a ski-cross HEAT: the bot in the first seed's lane, three of the start list skied beside it
npm run sim -- --mode bigAir --skis raven   # a BIG AIR jump (R37): the bot drops in tucked and straight and takes the kicker
npm run sim -- --mode knuckleHuck --skis hare   # a KNUCKLE HUCK's whole jam (R38): hit after hit off the knuckle, a nose butter each, to the buzzer
npm run sim -- --mode slopestyle --skis raven   # a SLOPESTYLE run (R39): the rail line of each rail section, then three jumps spun; `score` is the judges'
npm run sim -- --mode railJam --skis hare     # a RAIL JAM's whole jam (R40): a different feature every hit, to the buzzer; `score` is the panel's mark for the session
npm run sim -- --mode halfpipe --skis raven  # a HALFPIPE run (R41): wall to wall down the pipe, a trick a hit; `score` is the panel's mark for the run
npm run sim -- --mode moguls --skis ibex     # a MOGULS run (R42): a turn a mogul, a trick an air bump; `score` is the formal score out of 100
npm run sim -- --mode dualMoguls --skis ibex   # a DUAL MOGULS qualification (R43), alone in the blue lane; `--heat` a first dual against a rival skied in the red, `place` 1 or 2 and `score` his votes of 35
npm run sim -- --mode aerials --skis kestrel --rider light   # an AERIALS qualification jump (R44), `--plan bLFF` for another jump; `score` the formal score × DD, `hrsh` 1 on a landing past what the legs take whole (a triple's, as a real one's)
npm run sim -- --json out.json
```

## Reading the table

- **`pow`** is how much of the piste lies under a drift (R17) — the column the catalog is read against. `--skis all` ends with one row a seed, every pair's run time and a `*` on the quickest: no pair should win them all, and the powder pair should take the powder runs.
- **`fin` NO** on any seed is a regression until it is explained: the bot is a competent skier, and a map it cannot finish is a map a player will not finish either — or a skier that cannot get down what the generator builds.
- **`time`** is the run from the start line to the finish, top to bottom, with every slalom gate missed charged on it; a resort's course (R28) runs 0.8–4.8 km, so at the bot's pace it is a minute and a half off the nursery to five minutes off the peak — read it beside `len`. A jump across every seed is a skier that got slower or a bot that got timid; a jump on one seed is that map.
- **`grade`** is the colour the course measures: its steepest run's (R28).
- **`mean`** sits around 40–50 km/h for the bot today (a recreational skier's pace on a groomed piste; a downhill racer's tuck would be twice that), **`top`** near a hundred.
- **`air`/`jmp`** are the kickers on the course — none down a short green, a dozen down a black. Fewer jumps than kickers is a kicker the bot takes too slowly to leave the snow; `best` over 2.5 s is a lip overshot.
- **`hrsh`** counts landings past `air.harshSpeed`: a few is a kicker whose landing the bot's plan misjudges; many is a landing model gone hard.
- **`tree`, `rst`, `auto`** should be zero or nearly. `tree` counts every `hit` — a trunk or a post (a lift's tower, a floodlight mast, `posts.ts`). A hit on a generated map is the bot leaving the piste (R14 keeps the corridor clear; the masts stand past its edge) or a tower the lift's planner could not slide off a run; an automatic reset is a skier down or bogged.
- **`wipe`** must be zero on a solo run: every wipeout threshold (`TUNING.crash`) sits well past anything a clean run meets, so a wipeout there is a threshold come down into clean skiing or a bot that got worse. In a race a shoulder can put one down.
- **`miss`** is a gate skied past; on a resort's course every one between the start gate and the finish is a SLALOM GATE set off the line, and one missed costs three seconds and the run goes on (`cps` is then short by it). The bot skis the gate line, so a miss is a weave it could not make — a gate set wide off a steep pitch, or one just past a kicker's landing.
- **`score`** is what the run banked (`tricks.ts`). The bot turns nothing, so on a race map it is the air and the ground the kickers threw it across, combo by combo — a fall across every seed is a kicker that stopped throwing.
- **`digest`** changes with ANY change to the physics, the bot or the generator, and must not change between two runs of the same tree — `tests/determinism_test.ts` holds that.

## The bot (`engine/sim/bot.ts`)

A deterministic skier that reads the same `GameState` the HUD reads and produces the same `SkierInput` a thumb produces; it never reaches into the physics — what it knows about the skier it reads off `limits.ts` (the terminal speed on a grade, the edge at a speed, the carve's curvature, the corner grip, the braking). Its decisions, in the order they are made every step:

- **Where it is**: the nearest point of the piste, restricted to the stretch between the last gate it took and the one it owes — so a traverse's return leg is never mistaken for its own, and a gate gone past is a gate missed rather than a gate found again.
- **What it steers at**: a point `lookBase` + `lookPerSpeed`·v metres further down the centreline — on a course of slalom gates down THE GATE LINE through them (`gateLineAt`, R28), the weave's curvature read into how fast it may go — or down its LANE (inside a slalom gate's own width), the line a rival's slot started on (`Rival.lane`, m right of the centreline), held in from the piste's edge by a margin that grows with speed, so the field holds its slots out of the gate and closes on the racing line as it gathers pace; the player's stand-in skis the centreline — against the heading its yaw rate is carrying it to; in powder it reads further ahead and asks for less edge.
- **Off the start line**: it poles out of the standing start and aims through the start gate onto the line.
- **How fast**: for every bend within braking reach, the speed its curvature allows at `cornerShare` of the corner grip less half the pull of the pitch under it down the fall line (`PITCH_PULL`: on a steep pitch the slope drags a skier out of a turn across it) — and no faster than the pair's sidecut still carves it (`carveSpeedOf`: the edge's lock eases with speed, and a long ski's runs out first) — less what skidding at `brakeShare` of the grip can take off before it, net of what the piste's fall gives back; a pitch steeper than the brake can hold is room OWED, so it comes to such a pitch slower than the bend's own speed (to a crawl at the least, `CRAWL`); for every on-piste KICKER, the speed its lip is taken at; a tuck where nothing needs the edge.
- **On a slalom (R31)**: it skis THE RACER'S LINE round the poles (`race-line.ts`: the setter's line, `slalomLineFast`, its swing either side of the course's middle rounded out on a steep pitch — `ROUND.per` more of it a unit of grade past `ROUND.from`, at most `ROUND.most` more — because past ~0.37 of grade a skid's drag no longer outweighs the pitch's pull, so a racer checks his speed with the shape of his turns) with the racer's technique (`technique.ts`) CUT HARD. Every step it PLANS (`slalom-plan.ts`): a few ways of steering — one edge now, another after — skied forward over `slalomHorizon` s, or `slalomReach` m of piste where that is longer, on its MODEL OF A CARVED TURN (`turn-model.ts`), which reads the physics' own limits: the edge rolled at its rate and never further over than its body is laid plus `skier.angulateMost`, or than the technique's legs stand it under him as he crosses under (`incline.ts`'s `edgeReach`, the very rule the physics reads), the carve that edge buys no tighter than the sidecut bends (`carveMost`, R·cos edge) or the corner grip turns the way, the way turned only by the snow's grip across skis pointed off it (so it goes on round the old turn until its skis have swung through), the lean following the turn's balance and crossing over only as the old turn's load lets go, the check pivoting its skis the way it steers, and its speed. Its two numbers of its own, the lean's lag (0.15 s) and the share of the corner grip the way is turned with (0.6), are fitted to the engine's open-loop run — the model skied on the bot's own inputs from every quarter second of seven slaloms against where the engine took him (the line 0.23 m off over 0.6 s on the root mean square; with the cross-under the lean's lag barely matters). It weighs every way by how far it strays from the line, the heading it leaves it with, a speed over what the course allows, a slide that would catch an edge (`crash.ts`), a change of the steer it holds (`slalomChange` = 6: a racer commits to a turn) and, far more, passing the gate owed on the wrong side of its turning pole by `slalomClear` (a closed gate crossed from one side to the other between its top pole and its foot) — the check its speed asks for weighed against none — and gives the first edge and the check of the best. It holds its speed to `lineSpeed` (the par's own): the line's bend at `slalomPace` = 0.65 of the cut-hard grip, the turn left once `slalomCross` = 0.15 s of crossing from one edge to the next is taken out of the stretch between two turns (the racer crosses under); faster, the crossing eats the turn and it misses gates. It skis in THE RACING STANCE, never tucked (`slalomStance`, the par's `PAR.crouch`), holds a check past `crash.catchSkid` while its skis still slide fast, and stands its edge down out of a slide only in the high-side's own zone (past `skier.slipSpeed` with no skid of its asking). Down the campaign's fourteen slaloms and the slaloms of seeds 1–16 it finishes every run in 43–79 s at 29–35 km/h on the mean and 40–56 at the most, within 5 % of the course's par (`par.ts`, reckoned on the same line); on seed 38's slalom (`make technique`) 36 km/h on the mean, a turn every ~1.04 s, 48° of edge at each turn's peak (to 70° at the most), a tenth of its turns tighter than 7.7 m and 3.5 body weights at the peak. Its outcomes are chaotic — one gate taken a little late re-rolls the run — so a change to it is proven on all thirty runs.
- **On a downhill (R32)**: it skis THE RACING LINE (`speedLineAt`: the course's middle relaxed to the least curvature inside its corridor, the speed gates centred on it) with the downhill technique CUT HARD, on a line-follower of its own (`downhill-steer.ts`): the edge the line's own bend asks for at its speed a moment ahead (`DOWNHILL_STEER.lead`), plus a correction onto the line read `lookBase` + `lookPerSpeed`·v metres down it against the heading its yaw is carrying it to. It holds the speed the line's SIGNED bend allows (`lineBendAt` — the line's swing and the piste's bend read with their signs, since its gates cut the inside of the bends) at the grip the skis cut hard hold (`cutGrip`) and no faster than the sidecut still carves it, and takes off what is over with a LIGHT check (at most `check` = 0.1 of the brake: a racer who skids at 120 km/h slides off the line), tucked wherever nothing needs the edge; in the air it reads the landing ahead (`landingAhead`) rather than the line. Down seeds 1–16 on the downhill pair (`make sim ARGS="--mode downhill --skis eagle --count 16"`) it finished every one on generator v5's courses; on v6's — whose runs start under their tops, so the network and the course with the most vertical came out differently — it finishes 13 of the 16, the other three (seeds 4, 6 and 10) disqualified for a speed gate missed, at about 85 km/h on the mean and up to 141 at the most, no landing harsh: the bot's line through those courses is the open work.
- **On a super-G (R33)**: the downhill's line-follower on the super-G's swung line, read closer (`SUPER_G_STEER`: the line's bend and its own turn read 0.15 s ahead, half the downhiller's — fed further it turns for the next swing before this one's apex and cuts inside the turning pole), on the super-G technique (its edge held at speed, `SUPER_G_TECHNIQUE`), the same light check and the same landing read in the air. Down seeds 1–16 on the super-G pair (`make sim ARGS="--mode superG --skis falcon --count 16"`; the downhill pair the same fifteen, about 2 % quicker on its smaller tuck) it finished fifteen on generator v5's courses — seed 4 runs inside gate 6 at 110 km/h, out of a neck onto a swing it cannot slow for — and 38 of seeds 1–40; on v6's, whose runs start under their tops so the network and its courses come out differently, it finishes 12 of the 16 (seeds 6, 7, 13 and 15 disqualified for a gate missed), the race maps themselves still pinned on v5. On v5 it ran, at 59–91 km/h on the mean and 87–127 at the most, about two kilometres in 80–110 s (a blue's or a long red's lowered start 130–140 s), within −5 … +10 % of the course's par (`superGPar`). Across all of them it crosses a gate 0.5 m inside the line on the median, 2.4 m at the 1st percentile; the line passes 3.5 m outside the turning pole.
- **On a big air jump (R37)**: the speed skier's hold (`speed-ski-steer.ts`) down the jump's straight line, tucked from the start gate and never checked, so it reaches the lip at the jump's design speed; off the lip it taps the edge twice, a 360, and lands it. Down seeds 1–8 on the big-air pair (`make sim ARGS="--mode bigAir --skis raven --count 8"`) it lands every one, none harsh, 1.0–2.9 s in the air (the wind each seed's sky deals moves it — a headwind lands it on the table), at 104–111 km/h at the most down the in-run.
- **On a knuckle huck (R38)**: the same hold down the knuckle's line, tucked onto the deck; on the deck it presses the nose (the lean at 0.7, under the flip's stroke gate), winds the butter right from 7 m before the knuckle, loads the pop from 5 m and lets it go 0.4 m short (`KNUCKLE_HIT`), and rides the air with its hands off so the butter is squared for it; landed switch, it holds the way it is going. The jam runs to the buzzer, the engine standing it back on the platform after every hit. Down seeds 1–6 on the Hare (`make sim ARGS="--mode knuckleHuck --skis hare --count 6"`) it rides 14–15 hits a jam, every one a NOSE BUTTER 180 landed, none harsh and no wipeout, about 1.4 s in the air at the most; the `time` column is the jam's 180 s and `jmp` its hits.
- **On a slopestyle course (R39)** (`sim/slopestyle-steer.ts`): a hold on a LINE across the course, read nearer than the speed skier's (`SLOPE_STEER`); into each rail section it takes the RAIL's line, stood up and checked to the section's design speed, and rides it — a 50-50 on the first, an edge tapped to swap onto a slide on the second, the nose pressed on the third — and lets it turn him out; down each jump's approach it tucks, and in the air throws a 360 right, a 360 left and a 720 right, the strokes refusing what the air cannot turn. Down seeds 1–16 on the Raven (`make sim ARGS="--mode slopestyle --skis raven --count 16"`) every run is home in about 57 s, every rail ridden whole, the three spins landed, none harsh and no wipeout, the top speed about 100 km/h; the `score` column is the section judges' total, about 57.
- **In a rail jam (R40)** (`sim/rail-jam-steer.ts`): the slopestyle hold on a LINE, read nearer (`RAIL_STEER`), onto a different feature every hit, left to right and round again; checked to the set's design speed before the features, and on each a trick it can hold — a nose press on the down box, a swap onto a slide on the flat-down rail and the rainbow, a tail press on the kinked box, a 180 out of a 50-50 on the kinked rail — then on over the finish line. Down seeds 1–8 on the Hare every hit is ridden whole and none is a fall.
- **In a halfpipe (R41)** (`sim/halfpipe-steer.ts`): down the middle into the pipe's mouth, then wall to wall — across the flat at 64° off the pipe's line (`PIPE_STEER.approach`), the skis left alone up the wall (the wall turns him, `pipe-air.ts` turns him round in the air), folded on the flat and stood up through the transitions to pump the speed back — a trick a hit off a plan of six (a grab, a 360 each way, an alley-oop 360, 720s), and out of the foot straight to the finish. Down seeds 1–12 on the Raven every run is home with six or seven hits and none a wipeout.
- **On a moguls course (R42)** (`sim/moguls-steer.ts`): out of the start onto the line, then an edge thrown from side to side on the moguls' own rhythm (two a mogul), aimed `MOGUL_STEER.swing` off the fall line and held to the track's middle, a skid set against the bumps over 9 m/s and the legs folded up each face; straight through each air bump's run-in, a 360 off the top one and a back flip off the bottom one when the flight left the snow climbing (a flight the strokes would not turn is levelled to the landing by the bot's own hands). Down each air bump's landing, once down on it, he scrubs the flight's speed back to his pace before the moguls start again — met at 13 m/s they threw him. Down seeds 1–16 on the Ibex every run is home in 26.5–27.2 s, scoring 70.8–73.1, none a wipeout.
- **Off an aerials kicker (R44)**: the speed skier's hold down the in-run and the out-run (`speed-ski-steer.ts`), and in the air the jump declared (`aerials-steer.ts`): every flip of the plan asked off the lip, each flip's twists tapped while that flip turns, a tuck flip held tucked; the flight paces the rest. The site's in-run is one length a kicker, so there is no start height to pick.
- **On a dual moguls course (R43)**: the moguls bot held to the middle of HIS LANE (`moguls-steer.ts` reads the lane's offset off `Level.dualMoguls`), and the rival in the other lane is the same bot with its brake set to a pace dealt to his skill (`BotProfile.mogulPace`). The sweep without `--heat` skis the qualification alone; with it, a first dual against the eighth-final rival out of the gates together, the run going on until both lanes are home and the votes read.
- **On a giant slalom (R36)**: the super-G's line-follower on the giant slalom's swung line, read closer still (`GIANT_SLALOM_STEER`, picked by `steerOf`: the bend and its own turn read 0.06 s ahead, the look 5 m and 0.22 s per m/s ahead — a turn every twenty-odd metres at 70 km/h comes round in well under a second), on the giant slalom technique (`GIANT_SLALOM_TECHNIQUE`), and each bend taken at 0.85 of the grip the cut would hold (`bot.ts`'s corner share): with a turn every 20–30 m there is no straight to win a wide line back. Down seeds 1–16 on the giant slalom pair (`make sim ARGS="--mode giantSlalom --skis chough --count 16"`) it finishes all sixteen first runs, none out, without a wipeout, at 67 km/h on the mean and 90 at the most; its par (`giantSlalomPar`) is the downhill's forward reckoning down the swung line scaled by 1.11, the bot's own median share over those seeds. The sweep skis the FIRST run; a sweep that stands up a second run hands it the first run's pair.
- **On a speed track (R34)**: tucked from the house to the timing zone's bottom line and straight down the track's middle — the downhiller's hold on a line with no bend to feed forward, read 15 m and 2 m per m/s ahead, the edge it asks a share of the speed skier's 20° (`sim/speed-ski-steer.ts`, `SPEED_SKI_STEER`); past the zone the run is over and the engine's run-out stands him up and stops him. Its par is the same clean run skied by the engine (`par.ts`'s `speedSkiPar`), and the bot lands within 0.2 % of it on every race map.
- **On a ski cross (R35)**: the piste-reader as everywhere, down the course's own line — the course IS the map's track — held a smaller margin off its fence (`CROSS_MARGIN`); in a heat each rival's LANE is the pack's to read (`cross-heat.ts`'s `crossLane`): his door's lane closed onto the line over the start straight, and the side with room when a slower racer is close ahead in it. Its kickers are the course's jumps and step-downs, planned like any (`kickerSpeed`).
- **In the air**: levels the pitch to the slope it is going to land on, with the lean.
- **Trees**: moves its aim off a trunk standing in its line.
- **Giving up**: asks to be reset after `giveUpAfter` seconds without a gate — `patience` times as long while it is still moving at `stillGoing` m/s or more, because a gale in its face on a traverse slows a skier to a skater's pace, not to nowhere.

A RIVAL is the same bot on a run of its own, its tuck capped at the pace it was dealt at the start line (`RACE.paceBand`).
