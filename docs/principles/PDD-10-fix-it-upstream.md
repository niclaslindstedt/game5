## Rule

A bug in a module that comes from the shared framework is fixed there, released, and pulled in by moving the tag. It is never patched by a local copy.

## Why

The framework exists to end drift between the sibling games.

## Prevents

Four games each carrying a slightly different fix of the same bug.

## Exceptions

None.
