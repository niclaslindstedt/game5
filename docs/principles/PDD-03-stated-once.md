## Rule

A fact the game decides (a ceiling, a sign convention, a tuning number, where a point is on the piste, which map a run is on) is written in one place and every reader asks that place. Where two files cannot import each other, a test holds the copies together.

## Why

Two copies of a number agree only until one of them moves.

## Prevents

The bot, the HUD and the physics each believing a different top speed; a drawing that no longer matches the spec it was drawn from.

## Exceptions

The parity pairs AGENTS.md lists, each held by a named test.
