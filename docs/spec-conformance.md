# Conformance with OSS_GAME_SPEC.md

[`OSS_GAME_SPEC.md`](../OSS_GAME_SPEC.md) at the repository root is this project's governing specification, and the committed copy IS the spec — a verbatim copy of the one the sibling games carry, self-contained, amended in a reviewed pull request, with no upstream document to reconcile against and no validator to phone. This page is the other half of that arrangement: **one row per chapter, a verdict, the evidence behind it, and — where the repo falls short — what closing the gap would take.**

It exists because a conformance claim with nothing behind it is a badge. A sweep walks the spec chapter by chapter and re-dates every row; a sweep that changes no code still updates this file, because a verdict with no date behind it is an opinion.

**This repository is a first vertical slice, ported from the sibling snowmobile game's tree**, and the ledger says so rather than rounding every unbuilt chapter up. A chapter whose subject is planned but not in the tree is **not yet built** — not N/A (the condition WILL apply) and not conformant (nothing is there to conform).

**Verdicts:** ✅ conformant · ◐ partial, with the gap named · ✗ not conformant · ○ not yet built · ⊘ deliberate deviation, with the reasoning · — not applicable, with the reason.

_Last walked: 2026-09-29, against spec v1.1.0 — the port walk, carrying the verdicts across from the sibling's ledger as the tree was renamed for a skier; the game-shape rows are the slice's contract rather than a fresh reading of the ported code, and the next walk re-reads them against the tree._
