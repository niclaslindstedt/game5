Support

Write in Discussions, or open an issue for something broken. Say which device you are on and what the game did; if it is about one mountain, the seed in the corner of the screen is enough to rebuild it exactly.

The game will not start

Building a mountain takes a few seconds on a phone, and longer the first time. If it never gets past the loading screen, the usual cause is a browser with WebGL turned off or a very old graphics driver. Try reloading once — the game keeps a copy of itself for offline play, and a reload replaces a half-downloaded one.

Where my times and settings live

On your own device, in the browser's or the app's local storage. Nothing is on a server, so clearing site data or deleting the app deletes them, and there is no copy anywhere to restore. See the privacy policy.

Does it need the internet?

No. One visit to load, and it plays offline afterwards.

A piste that is broken, or a gate that is not fair

Every mountain and the piste down it are generated from a seed, so they can be rebuilt exactly. Send the seed and roughly which gate it happened at, and it can be stood in front of and looked at.
