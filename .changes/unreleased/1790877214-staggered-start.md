---
type: Changed
title: The field no longer leaves the start gate in step
---

The rivals in a race react to GO each on their own — between a sixth and seven tenths of a second late — and each one's first stride lands on a different leg and at a different point of the stroke, so the start line pushes off and skates out of the gate as four skiers rather than one figure four times over. The pile-up the lockstep start made beside the player at the gate is gone with it. The rivals' paces and skis per map are unchanged.
